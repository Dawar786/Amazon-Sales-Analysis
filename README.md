# 📊 Amazon Sales Analysis (Excel Report)

This repository contains a detailed sales analysis of Amazon’s dataset, created entirely using **Microsoft Excel**.  
The project demonstrates how Excel can be leveraged for business intelligence and reporting without the need for programming.

---

## 🔍 Key Highlights
- Data cleaning and preparation using Excel functions  
- Pivot tables for dynamic sales breakdowns  
- Charts and graphs to visualize category-wise and time-based trends  
- Identification of top-performing products and seasonal sales patterns  
- Dashboard-style summary for quick decision-making  

---

## 🛠️ Tools Used
- **Microsoft Excel** (Pivot Tables, Charts, Conditional Formatting)

---

## 🎯 Purpose
The goal of this project is to provide clear insights into Amazon’s sales dynamics, helping businesses and analysts make data-driven decisions using Excel.

---

## 📂 Repository Structure
- `SALES_ANALYSIS.xlsx` → Main Excel file with analysis  
- `README.md` → Project documentation  

---

## 🚀 How to Use
1. Download the Excel file from this repository.  
2. Open it in Microsoft Excel (2016 or later recommended).  
3. Explore pivot tables, charts, and dashboards to view insights.  

---

## 📈 Insights
- Seasonal sales trends across different product categories  
- Top-selling items and customer preferences  
- Regional performance breakdown
